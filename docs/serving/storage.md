# Хранение перед подачей

- Бутылки хранятся горизонтально (кроме коротких сроков перед подачей), чтобы пробка не пересыхала.
- Красные вина не нужно специально охлаждать заранее — их можно недолго подержать в холодильнике перед подачей, если в зале жарко.
- Открытую бутылку, если она не допита, можно сохранить максимум 1–2 дня в холодильнике с пробкой.
