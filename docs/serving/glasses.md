# Бокалы

- **Белое вино** — бокал поменьше, с более узкой чашей, чтобы медленнее нагревалось.
- **Красное вино** — бокал побольше, с широкой чашей для контакта вина с воздухом.
- **Игристое** — узкий и высокий бокал (флюте) или тюльпан, чтобы дольше сохранялись пузырьки.
- Бокал всегда держат за ножку, а не за чашу — тепло руки не должно нагревать вино.
