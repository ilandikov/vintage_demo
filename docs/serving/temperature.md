# Температура подачи

| Тип вина | Температура |
|---|---|
| Игристое | 6–8 °C |
| Лёгкое белое, розовое | 8–10 °C |
| Плотное белое (с выдержкой в бочке) | 10–12 °C |
| Лёгкое красное | 13–15 °C |
| Плотное красное | 16–18 °C |

!!! warning "Частая ошибка"
    Красное вино не подают «комнатной температуры» современной квартиры (22–24 °C) — это температурный стандарт XIX века, когда в домах было прохладнее. При такой температуре алкоголь ощущается резче, а вкус становится «плоским».
