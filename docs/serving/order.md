# Порядок открытия и подачи

1. Покажите гостю бутылку этикеткой вперёд — гость должен подтвердить, что это именно то вино, которое заказывал.
2. Откройте бутылку у стола, аккуратно, без лишнего шума.
3. Если вино с пробкой — предложите гостю пробку понюхать/осмотреть только по его инициативе, это не обязательный ритуал.
4. Налейте небольшое количество (30–50 мл) заказавшему для дегустации.
5. После одобрения — разливайте остальным гостям по часовой стрелке, начиная с дам, затем мужчинам, хозяин/заказавший — последним.
6. Стандартная порция — 100–150 мл на бокал, бокал заполняется не более чем на треть.
