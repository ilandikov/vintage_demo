# Правила подачи вина

Базовые правила, которые должен знать каждый официант и сомелье заведения.

## Температура подачи

| Тип вина | Температура |
|---|---|
| Игристое | 6–8 °C |
| Лёгкое белое, розовое | 8–10 °C |
| Плотное белое (с выдержкой в бочке) | 10–12 °C |
| Лёгкое красное | 13–15 °C |
| Плотное красное | 16–18 °C |

!!! warning "Частая ошибка"
    Красное вино не подают «комнатной температуры» современной квартиры (22–24 °C) — это температурный стандарт XIX века, когда в домах было прохладнее. При такой температуре алкоголь ощущается резче, а вкус становится «плоским».

## Порядок открытия и подачи

1. Покажите гостю бутылку этикеткой вперёд — гость должен подтвердить, что это именно то вино, которое заказывал.
2. Откройте бутылку у стола, аккуратно, без лишнего шума.
3. Если вино с пробкой — предложите гостю пробку понюхать/осмотреть только по его инициативе, это не обязательный ритуал.
4. Налейте небольшое количество (30–50 мл) заказавшему для дегустации.
5. После одобрения — разливайте остальным гостям по часовой стрелке, начиная с дам, затем мужчинам, хозяин/заказавший — последним.
6. Стандартная порция — 100–150 мл на бокал, бокал заполняется не более чем на треть.

## Бокалы

- **Белое вино** — бокал поменьше, с более узкой чашей, чтобы медленнее нагревалось.
- **Красное вино** — бокал побольше, с широкой чашей для контакта вина с воздухом.
- **Игристое** — узкий и высокий бокал (флюте) или тюльпан, чтобы дольше сохранялись пузырьки.
- Бокал всегда держат за ножку, а не за чашу — тепло руки не должно нагревать вино.

## Декантация

Декантировать (переливать в графин) имеет смысл:

- Молодые плотные красные вина — для насыщения кислородом и смягчения танинов.
- Старые вина с осадком — чтобы отделить осадок от прозрачного вина.

Лёгкие белые и игристые вина декантировать не нужно.

## Хранение перед подачей

- Бутылки хранятся горизонтально (кроме коротких сроков перед подачей), чтобы пробка не пересыхала.
- Красные вина не нужно специально охлаждать заранее — их можно недолго подержать в холодильнике перед подачей, если в зале жарко.
- Открытую бутылку, если она не допита, можно сохранить максимум 1–2 дня в холодильнике с пробкой.
